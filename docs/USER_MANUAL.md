# BA Grid Master 用户手册

适用版本：**1.2.0**（versionCode `10`）。本应用给出的格子建议来自截图识别和概率计算，使用前请对照游戏画面确认。后面的 1.1.0 升级章节保留为历史记录。

## 快速开始

1. 在首页进入“权限管理”，允许应用显示悬浮窗。
2. 选择识别来源：
   - **屏幕捕获**：点击“启动悬浮助手”并同意系统捕获授权，然后在游戏内点击悬浮按钮识别。
   - **最新截图**：授予全部照片访问权限并启动助手；每轮先点“清屏”，保存一张新截图，再点“识别”。
   - **自行选择**：点击“选择图片”，在系统选择器中确认一张图片。此模式不需要整库相册权限或悬浮窗权限。
3. 将悬浮面板移出棋盘和左下物品卡区域。不要使用裁剪图、长截图或本应用生成的标注图作为识别输入。
4. 自行选择图片识别成功后，首页会显示按游戏覆盖设置合成的原图，而非完整调试标注图。点击进入大图，“旋转”在 0°/90° 间切换，不改变应用横竖屏；切换后仍可缩放。
5. 在“结果信息”核对棋盘坐标、物品形状与数量、格子状态和推荐原因。必要时保存原图或标注图反馈问题。

相册模式下，“清屏”会把面板降至 10% 不透明度 3 秒；0.5 秒后识别按钮即可使用。系统主动停止屏幕共享时，助手会自动关闭。

最新截图模式出现“识别”按钮时，其下方同步显示圆角矩形“临时隐藏”按钮。点击后悬浮窗暂时隐藏，检测到新截图或达到时限时恢复。时限位于“设置 → 悬浮窗 → 临时隐藏时间”，范围为 1–10 秒整数，默认 5 秒。其他模式不提供该按钮；它不是在系统截图键按下时自动拦截截图。此前实验性的安全悬浮窗开关已移除，不再通过 FLAG_SECURE 禁止截屏。

游戏覆盖推荐坐标使用描边文字减少遮挡，默认线宽为 2；可在设置中调整覆盖标注。自行选择图片的结果沿用同一组显示配置，完整诊断标注另在“结果信息”查看。

## 识别与标记

- 棋盘固定为 9列×5行，列标为 A–I，行标为 1–5。
- 格子调试符号：`·` 未翻开、`S` 已勾选、`E` 已翻开空格、`L` 点亮碎片、`C` 完成剪影、`?` 待确认。
- 左下三种物品只按从左到右记为 a、b、c，不猜测游戏内名称。
- 建议格后的 `*` 表示探索格；不带 `*` 的格通常来自物品补全。
- “有限前瞻”会比较当前收益和一次落空后的下一步收益；“贪婪”只选当前估计命中率最高的格。

## 经验坐标与黑边

“设置 → 截图与识别”提供两个相关开关：

- **经验坐标校正**：开启后，应用只在翻开不超过8格、棋盘和三张物品卡均可靠、严格正方形拟合置信度达标时记录坐标。相同来源和图片尺寸连续3次稳定后建立经验坐标。关闭后立即停止使用和学习，但不会删除已有记录。
- **画面黑边检测**：仅在经验坐标校正开启时生效。任一边发现至少5px连续黑边，本次临时停用经验校正及记录，改用画面内的现场定位。适合其他设备截图转发到本机、平板画面嵌入手机截图等情况。

可在同一页面移除全部经验坐标。屏幕比例、裁剪方式或游戏 UI 位置改变后，如定位持续偏移，建议清除旧记录并用开局稳定画面重新学习。

## 结果信息与排查

结果页会记录：

- 棋盘像素区域、9×5 几何置信度、正方形锚点数量及置信度；
- 左下物品卡、贴图、形状区、数量区和 OCR 原文；
- 整盘剪影候选的整体分、模板召回、剪影精度和候选差距；
- 经验坐标是否采用、拒绝、重新学习，或是否因黑边临时停用；
- 每格状态、已识别物品区域和最终建议依据。

出现问题时优先检查原图中的棋盘和三张物品卡是否完整、悬浮层是否遮挡、截图是否为最新画面。定位问题请同时保留原图和标注图。

## 1.1.0 相对 1.0.0 的升级内容

### 跨屏幕比例与区域定位

- 增加有效游戏画面预定位，棋盘和左下物品托盘在有效画面内独立搜索，不再直接套用整张截图比例。
- 支持左右黑边、平板截图转发后再截图等嵌入画面；黑边不会再把整机坐标误当成游戏坐标。
- 物品托盘改为多候选定位，并结合三张卡片的形状完整度选择结果，降低标题、边框等相似线条造成的错位。

### 棋盘几何

- 单格规格改为严格 `1:1` 正方形硬约束；现场定位、横纵线回退和经验坐标复检都必须满足同一格宽。
- 开局轮廓完整时，使用内部横纵网格线及可信 T/X 锚点联合拟合共享的亚像素格宽，并以棋盘中部锚点为主要中心依据。
- 实际小数格宽会一直保留到逐条格线生成时才独立取整；左右边界从中心向两侧计算，避免把小数误差跨9格累积到右侧。
- 棋盘最外缘的光泽内轮廓只作辅助，不再作为主边界，修复平板样本左右边缘向内收缩的问题。
- 翻格增多、交点消失时自动回退到横纵线定位，并可在满足误差限制时使用已学习的经验坐标；不会把交点数量作为所有主题的强制合法性条件。

### 物品卡、数量和抠图

- 贴图抠图改为从图片自身采样背景，不硬编码本次活动的蓝色主题；改善物品边缘和左下角贴图切分。
- 改进小尺寸形状点阵和三卡托盘识别，降低不同缩放比例下的漏检。
- 托盘候选会把完成卡中央的 Finish 视觉状态，以及完成后仍保留但变暗的左下形状标签和右下数量标签视为卡位证据，避免第三件完成后托盘整体左移一格；候选筛选阶段不额外运行 OCR。
- 物品形状采用实心矩形硬约束；压缩噪声可作为离群点剔除，但不会再输出 L 形、缺角或阶梯形清单形状。长轴预旋转以最短等价角显示，范围固定为 `-90°..90°`。
- 加强 `×N` OCR 和 Finish 判定。仅当某个数字缺失、假设为 `1` 后“剩余物品格数 + 已完成剪影格数”恰好为30时，才用经验规则恢复 `×1`；已识别但总数不是30时不会强制修改。

### 整盘剪影与冲突处理

- 新增整盘完成剪影匹配，在逐格检测遗漏物品尾部时，可用完整贴图剪影识别整个已翻开物品。
- 冲突不再简单拒绝剪影结果，而是联合比较整体分、模板召回、全局剪影精度、候选差距和占格合法性；高质量整体剪影可以修正局部单格误判。
- 剪影精度提高权重，候选置信度及采用原因写入调试信息，便于区分相似物品候选。
- 多色活动棋盘会从全盘重复出现的平滑整格色块判断覆盖主题；黄色、粉色等覆盖格不会再作为物品前景连成长条。

### 自行选择图片结果

- 首页结果卡只显示标题、建议和标注图片；点击图片进入全屏大图，不在首页堆叠旋转说明或完整诊断。
- 首页大图和“结果信息”大图都支持双击定位放大、再次双击复位、双指缩放、拖动与保存。
- 大图旋转只在 `0°` 和 `90°` 两种显示状态间切换，不会进入 `180°/270°`，也不会改变应用的竖屏方向；保存时保留当前显示旋转。

### 经验校正与诊断

- 增加经验坐标校正总开关，以及仅在其开启时生效的5px黑边保护开关。
- 经验记录增加严格门槛：完整三卡、少量翻格、无待确认格、高棋盘质量及高置信正方形锚点缺一不可。
- 结果页补充原图、完整标注图、坐标校正依据、数量 OCR、剪影候选与置信度，方便在未连接手机时仅凭调试截图排查。
- 新增“自行选择”图片来源，使用系统文档选择器读取单张图片并走完整识别流程；成功结果会以原图叠加推荐标注直接显示在首页，并支持独立旋转预览。

## 兼容性与已知边界

- 游戏主题、屏幕比例和画面嵌入方式可以变化，但棋盘必须仍为9×5且单格为正方形。
- 大面积弹窗、奖励结算、严重遮挡或缺失物品托盘时，应用会拒绝识别或给出“待确认”，不会用历史坐标强行生成结果。
- 经验校正按图片来源和像素尺寸分别保存。相同像素尺寸但内容被二次缩放、加边或移动时，黑边保护和角点误差限制会阻止不安全校正。
- 正式发行版使用项目长期发布证书签名；从 GitHub Releases 下载的 APK 可在后续版本中直接覆盖升级。自行构建但未签名或使用其他证书签名的 APK，不保证能够覆盖安装正式发行版。
