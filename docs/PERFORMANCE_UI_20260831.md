## 修改

- 为每次真实成功识别记录8个互不重叠阶段：输入采集、棋盘、数量OCR、预处理、物品分类、摆放匹配、补全建议、探索建议。
- 悬浮窗和结果页分别显示“识别：X ms · 推荐：Y ms”。摆放匹配归入识别，补全和探索归入推荐。完整报告另列采集/等候和总耗时；毫秒取整及流程调度可能让各段之和略小于总耗时。
- 旧记录/Mock没有计时信息时明确显示“未分段记录”，不伪造零耗时。
- 45格的详细像素判断保留为内部日志，不再生成结果页长列表；状态网格、汇总、种类候选和摆放说明仍保留。报告文本按结果缓存，避免无关重组重复生成。
- 切片按物品逻辑行列显示；4×2始终为两行四列，窄屏可横向滚动整体网格。
- 首页副标题改为“挖格子小游戏悬浮助手”。
- 匹配复用前景掩码、按角度缓存旋转边界、对相同渲染参数使用单物品单次匹配内的8MiB有界缓存。未减少候选数量、角度、缩放、平移、采样分辨率或修改判定阈值。

## 内部日志

```text
adb logcat -d -v threadtime BAGridAnalysis:I BAGridCells:D *:S
```

`BAGridAnalysis` 每次记录 `attempt`、source、totalMs、inputMs、recognitionMs、recommendationMs、boardMs、ocrMs、previewMs、objectMs、placementMs、completionMs、explorationMs。

`BAGridCells` 按相同attempt记录逐格状态和原始像素占比。Debug和Release均保留；仅写系统本机logcat，不上传、不写入截图、不记录相册路径。logcat是有限循环缓冲区，发生问题后应尽快导出；清空结果页不等于清空系统日志。
