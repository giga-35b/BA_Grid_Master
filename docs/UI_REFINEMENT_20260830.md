# UI 调整与验收（2026-08-30）

版本继续保持 0.1.0。本次没有更改 CV 判定、探索概率或落子规则。

## 页面

- 首页：启动栏；权限管理和使用说明为描边按钮；图片来源用无背景的单行下拉框，默认为屏幕捕获。选择相册时仍必须允许全部照片访问；切换来源停止助手。
- 设置：权限管理 / 悬浮窗 / 游戏覆盖标注 / 截图与识别 / 关于，点击进入二级页；顶部返回和系统返回均回分类列表。子页分别保留滚动位置。
- 权限：悬浮窗、相册采用相同状态行；应用权限设置另列入口。屏幕捕获仍与启动助手集成。2026-08-31 起移除非必要的通知授权请求和控件，保留前台服务所需通知。
- 关于：0.1.0、MIT、机管giga-35b；联系作者复制 `https://space.bilibili.com/15097920` 并提示指定文案。GitHub 暂未提供，按钮提示待发布，不复制空值或虚构地址。发布时修改 `ProjectLinks.GITHUB`。

## 悬浮窗

- 仅按钮 / 有限信息 / 完整信息三档。旧 DEBUG 存值迁移到 FULL；结果页完整调试报告保留。
- 按钮30–75dp，已有超范围配置自动收敛。窗口测量实际内容后更新尺寸并重新约束在可用屏幕内；重排在触摸事件分发后执行。短信息区可拖动，超高的完整信息区可滚动。
- 有限信息：建议格（探索格加星号）、探索置信度（估计命中概率 `1 - missProbability`，不是 CV 匹配分）、计算时间。不显示棋盘识别率、来源、物品概况。
- 完整信息另外显示识别图片像素坐标中的两个棋盘顶点、a/b/c 形状及剩余/总数、所有点亮和全开物品的清单。每类物品按左上角行、列排序编号，例如 `[a2 B2横]`；纵向为“纵”、正方形为“方”。没有可靠完整摆法时显示“左上?”与已见格，不假装已确定原点。
- 总数来自与当前已知形状/数量兼容的五种物品组合；只有所有兼容组合对该总数一致才展示数字，否则为 `?`。不拿剩余数充当总数。Finish 未识别出形状时仍标“形状?”。
- 相册模式继续保留小字安全提醒；失败、清屏和等待时显示操作提示，不复用旧识别结论。

## 覆盖与结果图

- 全部用户可见物品类型统一小写 a/b/c。格子坐标列号仍大写 A–I；结果页的 L/C 状态与内部组 ID 不是类型编号，仍保留用于排错。
- 新增“左下物品信息”开关，默认关闭。打开时在贴图下侧显示如 `a：3×1，4/4`，使用与棋盘相同的图片缩放和系统栏偏移，限制标签在可用屏幕内。覆盖窗仍不可触摸。
- 点击结果缩略图直接进入大图；第一次双击围绕点击位置放大3倍，已经放大后再次双击回到初始适配比例。保留1–8倍双指缩放和拖动，限制拖动越界；旋转或新图时重置。
- 移除“放大查看”与“复位”按钮；原图/标注切换及两者的保存按钮保留，导出依然是原始识别分辨率，不受缩放影响。

## 真机建议核对

1. 首页切换来源、权限入口、折叠说明；设置每个二级页返回，尤其保留屏幕授权失败/撤销时的停止行为。
2. 30dp/75dp按钮、三档信息、三个方向吸附；识别结果变长/变短时窗口自动适配，信息区点击不触发识别。
3. 物品标签、小写类型和大写列号、探索格星号；横屏/不同宽高比下左下标签不越过屏幕底边。
4. 缩略图点击进入大图，双击偏离中心的位置、再次双击复位、双指缩放及图片切换/保存。
5. 联系作者复制准确链接并提示；尚未发布的 GitHub 按钮不能覆盖剪贴板。
