# 浅色碎片识别与预处理诊断（2026-08-31）

## 问题与边界

用户提供的二周目截图中，H2 为海螺 c 的浅色角，B2 才是空格。
旧版将 H2 的低饱和度像素过滤为背景，后续种类/摆放匹配没有执行。
这不是降低摆放匹配阈值可以解决的问题。

本次修改在当前工作区实施，保留 `backups/BA_Grid_Master-1.0.0-baseline-20260831-005730`
不变；未重新冻结基线、创建正式签名、上传或安装。
版本仍为 1.0.0 / versionCode 2；本次产物应视为原基线之后的修复测试包。

## 实现

- 使用统一的 `FragmentPixels` 前景定义，覆盖彩色、米白/浅灰暖色像素。
  格子存在检测、种类外观统计、空间模板匹配及边界接触使用一致规则。
- 第一层结合开放/覆盖背景、连通前景、暗色完成剪影及未解释区域判断格子状态。
  浅色片段需要连贯面积证据，孤立噪点不判作物品。
- 新增 `UNCERTAIN`（截图标记 `?`），不当成空格或未开格，不用于经验坐标学习；
  探索入口与底层求解器均暂停额外探索。待确认格不排除可能的物品摆法，
  但包含它的候选不能用于确定性完整补开。
- 第二层保留点亮事实及候选种类的外观分。颜色证据不足时退回可行形状候选，
  不将该格改为空。原有候选筛选分 0.35 保留；浅色分布有单独统计桶。
- 第三层仍保留原有空间分、轮廓分、不同摆法差距门槛，未通过简单降阈值增加采纳。
- 对左下贴图先剔除分离的卡片白边，再估计长轴，避免新增浅色前景污染预旋转。
- 所有有效非正方形清单物品都生成水平参考预览（即使棋盘全未开），
  与匹配使用同一个旋转/归一化渲染器，每个逻辑格采样为 32×32。
  预览包含旋转角、网格线及按行编号的分格图；正方形明确注明改用边界方向定位。
  这是预处理参考，不是最终棋盘摆放，匹配仍搜索反向、横竖及小角度调整。
- 结果信息页的“展开所有识别信息”显示上述预览与三阶段诊断。
  预览保留分割透明背景，屏幕原图的转换规则不变。
