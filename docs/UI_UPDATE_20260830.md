# 三页 UI、启动授权联动与物品标注

## 本次变更

- 底栏：首页 / 结果信息 / 设置；独立滚动位置，切页保留原图/标注选择和详情展开状态。
- 首页：启动/停止、跳转权限管理、相册模式开关、默认折叠的使用说明。
- 结果信息：原识别调试功能完整保留，支持原图/标注预览、放大、保存与详细报告。
- 设置：实际权限入口及原有悬浮窗、覆盖、算法和截图设置。
- 屏幕模式：系统授权成功且捕获服务就绪后才启动悬浮窗；拒绝/取消/捕获建立失败提示“获取屏幕授权失败”。用户结束屏幕共享时停止整个助手。
- 相册模式不启动屏幕捕获；切换来源先停止助手，需要用户重新启动。
- 游戏内 A/B/C 固定对应左下物品顺序，标签为“A 点亮”“C 全开”；全开矩形物品仅一框一标签。空格灰框、“空”标签。字号及触摸穿透设置保持不变。
- 未知/多候选类型不强行编号；异常非矩形已见分组不画包含隐藏格的包围框。结果页细粒度调试标签保留，不与游戏显示混用。
