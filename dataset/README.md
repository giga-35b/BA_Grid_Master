# 截图回归数据集

本目录保留用户提供的游戏截图、照片和视频抽帧，供棋盘定位、形状、数量、碎片、剪影和跨分辨率识别回归使用。文件名和原始目录结构尽量保持不变，避免破坏测试引用。

- 所有视频文件均由根目录 `.gitignore` 排除；本地原视频不删除。
- `file_tree.txt` 包含人工动作/格子标注，是回归测试输入，必须保留。文件树生成脚本默认输出到忽略的 `generated_file_tree.txt`，并拒绝覆盖原始标注。
- `video/` 下的静态抽帧图片仍保留，目录名不表示视频也会上传。
- 部分历史说明引用本地原视频或性能记录，公开仓库不包含这些文件。
- 不把应用输出的标注图当成未经标注的识别输入；样本可能包含反例或遮挡，并非每张图都代表应识别成功。
- 分享新样本前检查账号标识、昵称、聊天通知等可见信息；公开图片本身也可能包含个人信息，文本秘密扫描不能代替人工审核。
