# BA Grid Master

《蔚蓝档案 / Blue Archive》9×5 挖格子小游戏的非官方 Android 悬浮助手。根据截图识别棋盘、物品形状和剩余数量，给出补全或探索建议；不会自动点击游戏。

当前源码版本：**1.1.6**（versionCode `9`）。项目地址：[giga-35b/BA_Grid_Master](https://github.com/giga-35b/BA_Grid_Master)。

## 功能

- 三种来源：屏幕捕获、相册最新截图、手动选择图片。
- 识别棋盘网格、已翻开空格、点亮碎片、完成剪影及左下物品清单。
- 使用边缘纹理、合法形状约束和局部贴图匹配补全物品；条件满足时至多增加一个探索格。
- 可拖动和吸附的悬浮窗；覆盖标注不拦截游戏点击，样式可在设置中调整。
- 最新截图模式提供“临时隐藏”，仅在出现“识别”按钮时显示；隐藏 1–10 秒（默认 5 秒），检测到新截图后提前恢复。
- 自选图片把游戏覆盖标注合成到原图，使用设置中的覆盖样式；详细调试标注仍在“结果信息”查看。
- 大图支持双击/双指缩放、拖动、保存及 0°/90°“旋转”切换。
- 本机保存配置与经验坐标，提供 OCR、格子状态及推荐依据等诊断信息。

识别结果不是游戏事实或校准后的概率。遮挡、缩放、低质量截图和新主题都可能导致误判；请核对后手动操作。缺少可靠证据时可能只补开、不探索，或要求重新识别。

## 使用与构建

- [用户手册](docs/USER_MANUAL.md)：授权、三种模式和结果排查。
- [构建说明](docs/BUILDING.md)：已验证的 JDK、Android SDK 37.1、Gradle Wrapper、测试和签名边界。
- [策略说明](docs/STRATEGY.md)、[调试说明](docs/DEBUGGING.md)、[架构说明](docs/ARCHITECTURE.md)。

```powershell
# 配置 JAVA_HOME 和 ANDROID_HOME 后，在仓库根目录执行：
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease --no-daemon
```

支持 Android 8.0（API 26）及以上。当前不提供公开 APK；正式签名完成后计划通过 GitHub Releases 分发。`assembleRelease` 目前产生未签名 APK，本机非 debug 测试包也不等同于正式签名发布包。

## 数据、隐私与历史记录

[数据集](dataset/README.md) 保留截图、照片及抽帧，**不包含视频**。缓存、构建输出、签名文件、录制日志和本地版本备份不提交。

应用代码中的截图采集和识别在本机执行，当前应用 Manifest 未声明网络权限。主动分享截图、调试报告或 Issues 时，请自行检查账号信息、通知和其他可见个人信息。

`docs/` 内带日期的回归与性能报告是历史记录，可能引用未随源码发布的本地视频、备份或旧构建产物；当前操作以用户手册和构建说明为准。1.0.0 基线及 GitHub 整理前的 1.1.6 备份仅保留在维护者本机，不放进公开仓库。
